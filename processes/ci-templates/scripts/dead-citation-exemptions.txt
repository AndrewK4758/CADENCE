# dead-citation-exemptions.txt -- BTG-083 (AC-2)
#
# An ALLOWLIST of paths whose `specs/<id>/` citations are exempt from the
# dead-citation gate. It FAILS CLOSED: a citation in a file matched by no entry
# here and named in no baseline entry is a FAILURE. A denylist would fail open as
# the artifact set grows, which is the anti-pattern CADENCE_ORG.md Facet 1 names.
#
# This file is PERMANENT-BY-DESIGN. It may grow, but only with a recorded reason.
# It is deliberately a SEPARATE file from dead-citation-baseline.txt, which
# records temporary DEBT and may only shrink: the two have opposite lifecycles,
# and sharing a file would let debt quietly acquire the status of design
# (BTG-083 DEC-004).
#
# THE FOUR DISPOSITION CLASSES (BTG-083 DEC-001) -- documented here, not only in
# the spec, so an agent adding an exemption reads one file:
#
#   A  live pointer      a citation whose purpose is "go read this now"
#                        (a `# Spec:` / `# Contract:` / `# References:` comment).
#                        REPOINT it to archive/<id>/. Never exempt.
#   B  generated         a citation inside a compiler output tree.
#                        REGENERATE from source. Never hand-edited, never exempt.
#   C  historical        a PAST-TENSE record of what was true at a past moment.
#      narrative         EXEMPT, byte-preserved -- rewriting it falsifies a
#                        historical record.
#   D  self-referential  a citation inside the spec artifacts of a ticket whose
#      subject           SUBJECT is the dead path. EXEMPT, byte-preserved -- a
#                        ticket must be able to write its own subject matter.
#
#   A-f functional       a citation that is CODE (a filter argument, a variable
#       predicate        binding, a path addressed against a historical git ref).
#                        Case by case, NEVER blanket -- repointing one can break
#                        working code. Not exempt by default; it is read and
#                        dispositioned individually.
#
# FORMAT -- one entry per line:
#
#   <path-pattern> | <class> | <reason>
#
# The pattern is matched ANCHORED against the whole repo-relative path, never by
# substring or prefix resemblance:
#   - a pattern ending in `/`  matches that directory and everything under it
#   - a pattern ending in `**` matches that prefix and everything under it
#   - a pattern of the form `<path>:<line>` or `<path>:<line1>-<line2>` (added
#     BTG-340 DEC-076) matches ONLY the named line(s) of the named file, never
#     the whole file -- the GRANULARITY an A-f (functional-predicate) citation
#     needs: one specific line is dispositioned CODE, not every OTHER citation
#     the same file happens to carry. Reserved for class A-f; a whole-file
#     exemption (any other pattern below) still covers every citation in the
#     file, which is correct for classes C/D but was the exact blind spot
#     btg-129-retirement-shape.test.sh R-4 named for A-f.
#   - any other pattern must match the path in full
# So `docs/policies/cadence-surfaces.md` exempts exactly that file -- not
# `docs/policies/cadence-surfaces.md.bak`, and not a sibling in the same
# directory.
#
# The class letter is mandatory and the reason is mandatory: an unreasoned
# exemption is indistinguishable from debt, and is reported as
# `citation.exemption.unreasoned`.
