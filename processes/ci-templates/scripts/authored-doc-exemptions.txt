# authored-doc-exemptions.txt -- the org-token exemption ledger the
# authored-document gate consults (BTG-191).
#
# ADOPTER-OWNED DATA, NOT FRAMEWORK DATA. This file is the ONE place the
# authored-document gate's rules keep repository-SPECIFIC content: every row
# below names a path in THIS repository and quotes a phrase from THIS
# repository's history. `/cadence-adopt` therefore copies this file with its
# ROWS STRIPPED -- an adopter receives the header, the grammar and an empty
# ledger, and accrues their own rows against their own tree. It is create-once
# and is excluded from `/cadence-upgrade` merges, exactly like the other seed
# registers, so an adopter's rows are never overwritten by ours.
#
# WHY THE ROWS ARE NOT IN THE GATE ITSELF. They were, and that was a defect: the
# four gate scripts ship to every adopting repository through COPY_PATHS, and
# carrying these rows there would have shipped this organisation's live project
# keys into every adopter's tree. Nothing would have caught it, either -- the
# gate derives its own scan scope from the footprint descriptor, which classes
# `ci-templates` as framework-development and enumerates nothing beneath it, so
# the guard could not see its own leak. Splitting the DATA out of the CODE is the
# same split `dead-citation-gate.sh` already makes to `dead-citation-exemptions.txt`,
# and it is what keeps the code portable and the data local. Found at code review
# cycle 1 (blocking B-1); recorded in decisions.md.
#
# THE ROWS ARE NOT GENERICISED, and that is deliberate. An occurrence naming a
# CONCRETE LIVE OBJECT ID is PROVENANCE -- its citation IS its evidentiary value
# -- and scrubbing one would destroy an incident record rather than protect
# anything. That ruling is BTG-095's own, restated in the narrative below. The
# fix is to stop SHIPPING the rows, not to falsify them.
#
# ROW GRAMMAR, identical to the gate's other ledgers:
#
#     <repo-relative-path>|<anchor substring>|<reason>
#
# A row matches only when the offending line CONTAINS its anchor. An empty or
# path-wide anchor excuses every future line of a growing file, and the gate
# reports such a row as a violation in its own right. Blank lines and lines whose
# first non-space character is `#` are ignored.
#
# References: archive/BTG-191/decisions.md ; archive/BTG-095/decisions.md ;
#             archive/BTG-175/decisions.md ; archive/BTG-176/decisions.md DEC-054.
